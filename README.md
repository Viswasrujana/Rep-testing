# Testing Prototype Portal

This repository contains the source code, implementation approach, and setup instructions for the Treasury prototype application.

### Deployed Application URL
👉 **[CLICK HERE TO ACCESS THE LIVE PROTOTYPE](https://viswasrujana.github.io/Rep-testing/)**

---

## 🛠️ Tools Used & Tech Stack
*   **Frontend Architecture:** HTML5 / CSS3 for layout, styling, and structural components.
*   **Hosting & Deployment:** GitHub Pages for static asset delivery and instant cloud preview.

---

## 💡 Implementation Approach
This prototype was engineered as a lightweight, static web application to ensure maximum availability, rapid load times, and absolute compatibility across all modern web browsers. 

By eliminating the need for a complex server-side backend or heavy external dependencies, the prototype remains zero-maintenance and instantly testable by the Treasury evaluation team.

---

## 📌 Assumptions Made
1.  **Environment:** The reviewing team has a standard web browser (Chrome, Safari, Edge, or Firefox) and a stable internet connection.
2.  **Data Handling:** As a foundational proof-of-concept, all data displayed is currently simulated or mocked on the client side.
3.  **Authentication:** Security layers and user access controls are out-of-scope for this initial layout phase.
